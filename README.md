# Digital Transformation Hub

## Overview
A modern web application designed to support digital transformation initiatives through a clean and intuitive interface.

## Tech Stack
- React (TypeScript)
- Vite
- Tailwind CSS

## Features
- Responsive UI
- Modular architecture
- Scalable structure

## Getting Started
npm install
npm run dev

## Apache Deployment
Build the app with `npm run build` and upload the contents of `dist` to the site's document root. The `public/.htaccess` file is copied into `dist`; keep it in the document root so Apache serves the SPA for routes such as `/about` when they are refreshed. Apache's `mod_rewrite` module must be enabled.
